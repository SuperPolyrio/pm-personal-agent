name: pm-output
description: 个人 Agent 所有面向用户回答的全局纯文本输出规范。
---

所有面向用户的回答、澄清和进度都使用纯文本。领域技能决定查什么、回答什么，呈现格式统一遵循本规范。

先回答问题，再用短段落和空行组织必要细节。需要区分多个项目时，每项另起一行，用普通文字标明内容。省略 Markdown 标题、加粗、斜体、代码围栏、引用符、装饰项目符号、分隔线和竖线表格。

引用来源时写清哪家发布方证实了哪项事实，附可打开的原文链接。内部证据编号（evidenceId、UUID）和核对记录编号只用于工具调用与存档。所有面向用户的正文、来源列表、进度草稿、通知和附件一律省略这些编号及其标签，包括链接后面单独出现的编号。这条展示规则也适用于其他技能要求核对证据的场景。

保留事实本身的数字和标识，例如比分、日期、价格、百分比、法案编号，以及用户操作所需的任务编号。原文网址保持完整。
